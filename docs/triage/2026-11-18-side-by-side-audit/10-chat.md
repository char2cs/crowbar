# 10. Chat view (CHAT)

> **How each app loads the chat bundle.** Tauri: one WebKitGTK webview at `tauri://localhost` serves develop's `web/dist` SPA; the chat is a React component in the same page as sidebar and tabs; `window.__CROWBAR__ = {mode:'local', endpoint/api:'crowbar://localhost'}`; API calls go over the `crowbar://` scheme to the daemon. Rust: GPUI draws sidebar, tabs and pane header; each chat pane is its own wry/WebKitGTK webview at `crowbar://local/panes/core/chat/index.html`, served by `PaneProtocol` from `CROWBAR_PANES_DIR` (this branch's `app/panes` `build:panes` output); a bootstrap script sets `window.__CROWBAR__ = {api:'crowbar://local', host:'local'}` plus the sdk@1 IPC channel; API calls go through `DaemonTransport`. `/fonts/` routes to `<panes_dir>/fonts/`, which the shipped bundle does not have, so `CalSansUI.woff2` never loads and Rust chat text renders in a fallback sans (Geist Mono and Instrument Serif come from @fontsource and match). **F** in Difference means this font-only difference.
