# Rust tree: file mapping

Companion of `docs/plans/2026-11-18-rust-tree.md`. Every `.rs` file listed by `git ls-files 'app/**/*.rs' ':!app/desktop/vendor/**'` appears once.

Format: `old path (relative to the old crate) → new path (relative to app/)`. After `·`: the type rename and the note. `DELETE` lines give the reason. Files kept but with strip code cut out say so in the note; cutting that code is a behaviour change and never happens in a move commit.
