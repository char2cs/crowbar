> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax. **Invoke the `go-style` skill before writing any Go.**

> **INDEPENDENT of 3A/3B/3D** — touches only `internal/engine/lsp/`, new API routes, and a new WS topic. Uses the existing `workspace.Workspace.Get` (Wave-0/3A) to resolve a `wsId` → `worktreePath`; if 3A isn't merged, the Wave-0 `Workspace.Get` already exists. **Ship after the rest is green** (the editor works without it).

**Goal:** Build the backend as an LSP host/proxy: spawn language servers (`gopls`, `typescript-language-server` shipped; `pyright`/`jdtls`/`clangd` config-extensible), speak JSON-RPC over stdio, serve request/response features over REST, push diagnostics over a WS topic, with frontend-driven document sync (track open URIs, replay `didOpen` on respawn), lazy per-workspace lifecycle with an **independent refcount**, and graceful absence when no server is installed.

**Architecture:** `engine/lsp/` mirrors the spec layout: `registry/` (language→command), `server/` (one stdio JSON-RPC process), `manager/` (per-workspace server pool, lazy spawn, refcount), `convert/` (LSP↔Crowbar DTO). REST handlers forward synchronous features; a `Diagnostic[]` broadcaster (the project's 8th topic) pushes `publishDiagnostics`. Document content stays in the browser — the backend tracks only the set of open URIs per workspace and replays `didOpen` on respawn.

**Tech Stack:** Go 1.26.2, JSON-RPC over stdio (stdlib `os/exec` + a minimal LSP framing codec; **no new heavy dep** unless an LSP lib is already vendored — grep first), gin, the existing `ws.Broadcaster[T]`, testify. Module `github.com/char2cs/crowbar/api`.

```go
// Package protocol implements the minimal LSP JSON-RPC surface Crowbar needs:
// id-correlated request/response and publishDiagnostics notifications (10 §1).
package protocol

import "encoding/json"

// Request is an outbound JSON-RPC request.
type Request struct {
	JSONRPC string          `json:"jsonrpc"`
	ID      int             `json:"id"`
	Method  string          `json:"method"`
	Params  json.RawMessage `json:"params,omitempty"`
}

// Notification is a JSON-RPC notification (no id).
type Notification struct {
	JSONRPC string          `json:"jsonrpc"`
	Method  string          `json:"method"`
	Params  json.RawMessage `json:"params,omitempty"`
}

// Response is an inbound JSON-RPC response or server-initiated message.
type Response struct {
	JSONRPC string          `json:"jsonrpc"`
	ID      *int            `json:"id,omitempty"`
	Method  string          `json:"method,omitempty"`
	Result  json.RawMessage `json:"result,omitempty"`
	Params  json.RawMessage `json:"params,omitempty"`
	Error   *RPCError       `json:"error,omitempty"`
}

// RPCError is a JSON-RPC error payload.
type RPCError struct {
	Code    int    `json:"code"`
	Message string `json:"message"`
}
```
